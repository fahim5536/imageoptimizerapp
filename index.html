How to Use

Get started in minutes — no technical knowledge needed

01

Download & Install

  • Download the .exe file from the button above
  • Double click the installer
  • Click "Next" and follow the setup wizard
  • Launch "Image Optimizer" from desktop shortcut
02

Add Your Images

  • Click the drop zone or drag & drop images directly
  • Supports JPG, JPEG, PNG, WebP, AVIF formats
  • Add single or hundreds of images at once
  • See file names appear as chips below the drop zone
